## 1. Overview & Test Scope

The **Diagnosis Catalog & Directory Module** (`/admin/diagnosis`) is a clinical reference master database within the Amerck Care EMR system. It serves as the single source of truth for all diagnosis entries used across consultations, prescriptions, admissions, and medical reports.

### Key Functional Capabilities:
1. **Catalog Browsing:** Paginated viewing of global reference diagnoses (ICD-11 codes) and practice-specific custom diagnoses.
2. **Real-Time Directory Search:** Live filtering across thousands of medical terms by clinical description, condition name, or ICD code.
3. **Custom Diagnosis Creation:** Practice physicians can register custom diagnostic conditions with optional or required ICD codes.
4. **Custom Diagnosis Editing & Deletion:** Managing and updating existing clinic diagnoses with immediate synchronization across clinical modules.
5. **Global Diagnosis Reference Protection:** Global ICD reference conditions cannot be deleted by individual providers; modifying a global condition allows promoting it as a customized local entry (`Save as Custom Diagnosis`).
6. **Integration with Prescriptions & Admissions:** Master diagnosis catalog directly fuels autocomplete and chip tagging in `/admin/prescription` and `/admin/admissions`.

## 2. Test Execution & Credential Guidelines

> [!IMPORTANT]
> **Credential Security Standard:**
> - Credentials must **never** be hardcoded directly into shared test scripts, public repositories, or plain-text logs.
> - Store credentials strictly in `.env` files protected by `.gitignore`.
> - Automated test suite utilizes session storage state at `playwright/.auth/user.json` generated by `tests/auth.setup.js`.
